# 調剤録まちがい探しクイズ（2問お試し版）

## 概要
- 処方箋と調剤録を比較して、各問2か所の間違いを調剤録側で見つけます。
- 正解すると赤丸が表示され、2か所発見すると解説が出ます。
- 正解エリアでマウスカーソルが変わる仕組みは使用していません。
- PCは左右2列、スマホは上下表示です。＋／－ボタンで書類を拡大可能です。
- 2問終了で発見4/4か所と誤タップ回数を表示します。
- 本版にはGoogle Apps Scriptの結果送信は付けていません。

## 設問
- 第1問：処方日 08.10.23→08.10.22、グリコラン錠（GL）→MTに対応するメトグルコの後発品
- 第2問：分1 朝食後→分2 朝夕食後、薬Aロ45→薬Bロ59（この設問では新患の想定）

## 公開方法（GitHub Pages）
1. ZIPを解凍します。
2. ルートの以下8ファイルを同じリポジトリ階層へアップロードします。
   - index.html
   - style.css
   - script.js
   - question1_rx.png
   - question1_record.png
   - question2_rx.png
   - question2_record.png
   - README.md
3. Settings → Pages → Deploy from a branch → main / (root) → Save を選択します。
4. 提供されたURLからスマホでも利用できます。

## 運用メモ
画像はアップロードされた架空の処方箋・調剤録からレンダリングしたものです。実患者の画像を追加する際は、個人情報を確実に除去してください。
正解の矩形座標はscript.jsのquestions配列内のregions（画像に対する0～1の比率）で調整できます。
医薬品等の具体的な選択については研修資料として施設・薬局の運用に合わせ、薬剤師の監修を受けてください。
