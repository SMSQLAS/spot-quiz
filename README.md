# Spot quiz: 2 mistakes (v2)

調剤録の間違い探しクイズ、1問お試し版です。今回の画像は架空の処方箋・調剤録です。

## 変更点

- 調剤録の未収金を「-1060」から「0」に訂正済みです（問題には含めません）。
- 間違いは合計2か所：氏名の「てすと」、処方日「08.10.23」。
- 氏名は上下2か所に出ますが、どちらをタップしても正解として扱い、両方タップしても1か所分しかカウントしません。
- 調剤日「08.10.23」は今回の間違いではありません。
- 今回は動作サンプル1問のため、Googleスプレッドシートへの送信機能は含まれていません。

## ファイル

index.html / style.css / script.js / prescription.png / dispensing.png

## 公開方法

1. ZIPを解凍します。
2. 上記5ファイルを、GitHubリポジトリの同じ階層（ルート）にアップロードします。ZIPそのものをアップするのではありません。
3. リポジトリの Settings → Pages から、Deploy from a branch → main / (root) を選択して公開します。
4. すでに同じ名前のファイルを公開している場合は、変更したファイルを同名で上書きしてください。

## 正解位置について

3つの透明タップ範囲を設置していますが、上部氏名と下部氏名は同じ正解IDなので計2問ではなく1か所分です。タップ時は選ばれた氏名の位置に赤丸を表示します。
